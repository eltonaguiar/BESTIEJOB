- Dedupe on company+title+city, not URL; watch subsidiary aliases (SCIEX↔Danaher, Reonomy↔Altus, LGS↔IBM).
- Elite/Platinum SI partners (TCS, Cognizant, Infosys, Accenture, Deloitte, Capgemini, Wipro, HCL, KPMG, CGI) reliably post cadence-fresh Toronto SN/SF reqs; Rogers/Bell/Canadian-government SN/SF are sparse — check them but expect few hits.
- The hourly GitHub Action refreshes jobs.json/site but not README — the README-vs-feed delta is where the manual hourly merge adds value.
