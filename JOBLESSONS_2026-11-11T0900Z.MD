## Lessons

1. Adzuna's dated API (`max_days_old=2`, `sort_by=date`) is the only source consistently returning same-week Toronto ServiceNow/Salesforce postings; Job Bank and Eluta hang without hard timeouts — keep them out of the hourly path or wrap each request in a strict timeout.
2. Employer career pages (Bell Phenom, KPMG iCIMS, Scotiabank Workday) often publish postings without `datePosted`. Board rule is absolute-date-only, so they're excluded; keep undated leads (like Bell 431695) in a side list for manual date-checking instead of the board.
3. Indeed's "New" tag is not a date — four undated ServiceNow postings surfaced this run (APPTOZA Business Analyst/SPM Developer, Procom Platform Developer, Atlantis Consultant, Paralucent ITSM/HRDS Configurator). None are mergeable without a posted date.
4. Filled/closed postings (Bell 432824 System Administrator, Bell 432892 Senior Manager Platform Delivery, Scotiabank 603030017) still rank in search results — verify liveness ("not accepting applicants" / "has been filled" banners) before counting a hit as fresh.
5. Rogers' careers site lists dates per posting (Nov 7, Nov 6, Nov 4...) but returned zero ServiceNow/Salesforce roles this cycle; don't re-scan Rogers tech pages hourly — check the Rogers search page for "servicenow|salesforce" keywords instead.

## Decision

Nothing merged: zero new verified fresh jobs this cycle. Recording as null scan per the board's dated-only, deduped-first policy. No README.md or public/ changes; main branch and GitHub Pages unchanged from commit fa52e79.
