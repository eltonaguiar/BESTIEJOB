## Process notes / pitfalls
- fresh_ca_scan.py can exceed 300 s (Job Bank/Eluta slow) — run foreground with generous timeout or in background; do not re-run Adzuna-heavy scans back-to-back (503s).
- `sync_readme_to_jobs.mjs` is a silent no-op on the current README (mangled one-line table blocks) — write rows to jobs.json directly, rebuild `public/` with build_site.py, commit jobs.json + public/ together.
- Rebase rule: when the hourly workflow commits to origin/main mid-cycle, `git rebase origin/main`; resolve generated files (jobs.json/public/*) with upstream (`--ours`), keep README/lessons from your commit (`--theirs`), re-run build_site.py, amend, then fast-forward push.
- jobs.json CRLF/LF: git warns "LF will be replaced by CRLF" — cosmetic, content is valid JSON either way.
