### Key patterns / lessons
1. **Most fresh Canada SN/SF URLs are already on the board.** Of 43 fresh Canada SN/SF rows new to jobs.json, 42 were exact URL duplicates of existing README rows. Dedupe by normalised URL (strip query string + trailing slash) catches mirrors before they reach the table.
2. **Workday CXS is the best freshness oracle but is heavily rate-limited.** All Workday tenant searches (salesforce, bmo, td, moneris, bdo, caatpension, medcan, altusgroup, iko, huron, irvingoil, mckesson, brookfield, gdit, resolvetech) returned HTTP 429 this run → 0 Workday matches. Space tenant probes; don't retry blocked tenants hourly.
3. **LinkedIn guest API 429s after ~4 rapid queries while still returning HTTP 200.** Always test body length + digest distinctness, not just status. Fallback: open the LinkedIn jobs-search page in the browser and read `li a[href*="/jobs/view/"]` from the DOM.
4. **Workday tenant guessing burns calls.** Only known 200 pairs answer (bmo, td, cibc, manulife, interac, salesforce, accenture, gdit, ...). Guesses (capgemini, kyndryl, ibm, cgi, cognizant, telus, rogers, kpmg, scotiabank, intact, loblaw, cprail, rbc, pwc, sunlife, canadalife, desjardins, cnr, cppib, omers, otppb) return 422/404/empty. Discover site names from employer careers pages or search engines.
5. **Rogers careers is date-sortable and scrapeable:** `jobs.rogers.com/search/?q=&sortColumn=referencedate&sortDirection=desc` renders `<tr>` rows with absolute dates. Bell (`jobs.bell.ca`) renders an empty shell / (0) in browser → zero reqs, re-check weekly.
6. **Canadian public-sector portals are Radware-walled:** `gojobs.gov.on.ca` and `jobs.gc.ca` return captcha; do not retry. Use Job Bank as the proxy and trust only postings whose *title* names ServiceNow/Salesforce.
7. **Salesforce Platform Administrator / Platform Developer I (entry-level) are scarce.** Fresh SN/SF postings skew senior/architect (Technical Architect, Implementation Architect, CMDB/GRC/IRM architects). Junior Platform Admin/Dev I rarely appear — prioritize them when they do (e.g. "Sales Operations Coordinator / Junior Salesforce Admin").
8. **Known partners / elite partners that consistently post Canada SN/SF:** Accenture, Deloitte, PwC, CGI, KPMG, Infosys, Cognizant, Nityo Infotech, Pacer Group, AceStack, S I Systems, Dexian, SPECTRAFORCE, GDIT, BDO; plus end-users BMO, TD, RBC, Interac, Manulife, CIBC. ServiceNow-the-company posts only sales/SRE/security in Toronto.
9. **Adzuna recycles IDs — use the detail page's JSON-LD `datePosted`, not the API `created` date.** Old ads resurface under new IDs; dedupe by fuzzy company (strip Inc/Ltd/Corp) + title tokens, not URL alone.
10. **Build & publish:** `jobs.json` leads; README rows fill gaps. `sync_readme_to_jobs.mjs` is a silent no-op — write to jobs.json directly. Always `git diff README.md` after `jobs_merge_inbox.py` (it drops the table separator and glues the heading; fix separator + heading before build). Commit `[skip ci]` to avoid the chronic red board-invariants audits.
11. **GitHub Pages:** `pages.yml` redeploys on main push; verify live `jobs-data.json` carries the new URL after push (propagation delay).
