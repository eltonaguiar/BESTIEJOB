## 3. Resume defects — fix before spending on any cert

1. **Delete "Certifications under eaguiar2015@yahoo.ca email."** All three sources flag it. It invites
   verification friction and signals the Now Learning / Trailhead records sit under an address that
   isn't used professionally. Consolidate the accounts, then remove the line.
2. **Rename two certifications.** "Salesforce Certified Platform Administrator" → **Salesforce
   Certified Administrator**; "Salesforce Platform Developer" → **Platform Developer I**. A screener
   who knows the Salesforce cert tree catches this in seconds and discounts the whole section.
3. **Reconcile the two resume variants.** One drops the Salesforce block from the header, the other
   drops CIS-ITSM. Background checks surface exactly this kind of inconsistency.
4. **Make the tenure arithmetic explicit.** The summary says "6+ years" while the roles run
   2011→present with ServiceNow from 2017–18 onward — state "6+ years ServiceNow, 15+ in IT/data"
   rather than letting a screener do the maths.

## 6. Final recommendation — ordered, dated

**Primary path: ServiceNow** (recency intact — current role is ServiceNow since Jan 2025).

| When | Action | Why this order |
|---|---|---|
| **Week 1 (no cost)** | Fix the four resume defects; write the two-page CMDB/IRE architecture artefact | Costs nothing, removes screening friction, and the artefact does more for interviews than any single cert |
| **Weeks 2–6** | **CIS-IntegrationHub** (full cert) | Cheapest credibility upgrade and the highest-bill-rate specialty; directly supported by the Feedhub / 15-system / Scripted REST work |
| **Weeks 6–12** | **CIS-ITOM** | Converts the Metrolinx Discovery + CIBC CMDB reconciliation into a defensible specialty claim |
| **Weeks 12–20** | **CIS-SIR** (or the ATF-depth work if SecOps roles do not appear) | Opens SecOps/IRM, where the RBC vulnerability background is genuinely rare |
| **Months 5–7** | **Databricks Data Engineer Associate + dbt** *or* **SnowPro Core** | Moves the "800k-record reconciliation" story from ITAM consultant toward CMDB data engineer, which pays more |
| **Months 7–9** | **IAITAM CSAM/CHAMP**, then **AWS SAA + Terraform Associate** | Vendor-neutral ITAM credibility, then cloud literacy for Discovery/Service Mapping work |

**Secondary path: Salesforce** — only if a current side project starts **now**.

| When | Action |
|---|---|
| Weeks 1–8 | **PD II** (the BMO material already qualifies) plus a small public Salesforce project or open-source contribution — the recency, not the badge, is what is missing (last SF work ended Jan 2025) |
| Weeks 8–16 | **Salesforce Certified Administrator** (correct name), then **AI Specialist** |
| Months 4–6 | **Agentforce Specialist**, then **MuleSoft Developer I** or **Workato Automation Pro** |
| Later | **Data Cloud Consultant**; architect track only after PD II + 2 years of current SF work |

**One-line answer:** earn **CIS-IntegrationHub first** (ServiceNow primary path), keep **PD II** as the
first move if Salesforce ever becomes primary, and spend the first week on the resume fixes and the
architecture artefact — which cost nothing and change how every application is read.
