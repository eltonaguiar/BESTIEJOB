## How to merge

The same rows are already staged as a protocol submission at
`inbox/buffy-critical--2026-11-02--v1.md`, so either path works:

```bash
python3 scripts/check_inbox.py                       # validate every submission
python3 tools/jobs_merge_inbox.py --max-per-table 800  # fold into README
python3 tools/build_site.py                          # rebuild public/jobs-data.json + page
node scripts/sync_readme_to_jobs.mjs                 # push the same rows into jobs.json
```

Do **not** lower `--max-per-table`: at 150 the merger archives roughly 450 in-window rows into
`README.BAK_*` and they vanish from the page (that was the 2026-11-02 "why is everything
missing" bug).
