## Patterns / lessons for future agents

- **Workday CXS is unreliable for same-cycle freshness:** HTTP 429 on every Canadian board this run → zero Workday employer-board captures. Space manual Workday probes or leave Workday to the CI cadence; don't treat 429 as "no vacancy."
- **LinkedIn guest + Adzuna details hit walls:** LinkedIn guest 429 and Adzuna.ca CloudFront "request could not be satisfied" — corroborate via search mirrors (ZipRecruiter/Talent.com/Indeed) and employer pages before merging; a 200/401/403 liveness check is the minimum gate.
- **Dedupe is URL-normalization only:** the merger dedupes by normalized URL (tracking params stripped). The same requisition re-advertised on Adzuna/LinkedIn/Eluta/Job Bank under different URLs survives URL dedupe — a `title\|company\|city` fingerprint catches those, but the merger does not apply it. Fingerprint-check manually when sources disagree.
- **README table sanity matters:** `jobs_merge_inbox.py` refuses to write if dated rows can't be parsed back out (glued-row corruption). This run's tables were parseable, so the additive merge succeeded. Check `rows_are_readable` output before assuming a merge will land.
- **Concurrent CI scans race with cron:** `origin/main` advanced mid-run (c6ddeb2). Push was rejected; rebase onto `origin/main` then push. Resolve job-data file conflicts with `--theirs` to keep a self-consistent build (README + jobs.json + public/ must match each other). **Never commit** the unrelated `ServiceNow_Learning_...` submodule pointer or untracked scratch files (`raw/`, `leads-*.jsonl`, `README.BAK_*`).
- **Known partners/sponsors are leads, not vacancies:** Ateko (routes SN to FX Innovation, SF to ADP), Lane Four, Pentio (Toronto Select), Fujitsu (Elite implementation), Cognizant, NeuraFlash, CloudFulcrum, Slalom, ServiceNow Inc., Salesforce Inc. — resolve the official careers path before counting a role; a partner office or sponsorship is not a posting.
- **Telcos / government not scanned this cycle:** Rogers (jobs.rogers.com historically 404/9-byte Phenom shell), Bell (jobs.bell.ca / jobs.bce.ca Phenom client shell, no server datePosted), Government of Canada (jobs.gc.ca / GC Jobs captial/rate-limited, Job Bank title-only proxy). Recommend a manual Rogers/Bell/GC sweep on alternate cycles, not hourly.
- **Zero fresh Salesforce entry-level / Platform Admin / Platform Developer I this cycle** — Salesforce fresh hits were Senior Specialist, Technical Architect, Administrator, Loyalty Developer. The entry-level track remains the hardest to surface; consider targeted "Platform Developer I / Associate Admin / Junior" keyword queries on employer portals next cycle.
