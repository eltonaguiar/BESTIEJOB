## Patterns / lessons for future agents
1. **Adzuna 503 is not fatal.** All 28 Adzuna fresh queries 503'd this hour; the scan still merged 692 fresh jobs from Workday/LinkedIn/SmartRecruiters/Greenhouse/remote feeds. Never let one aggregator kill the whole scan.
2. **LinkedIn guest throttles hard (HTTP 429 after ~4 rapid queries).** Keep ≤2 workers with ~2s between requests; retry later in the same run rather than declaring the source empty.
3. **Dedupe by normalized URL, plus company+title as a backstop.** Same requisition arrives under LinkedIn/Workday/Adzuna/employer-ATS URLs; URL-only dedupe misses Adzuna redirect URLs vs. LinkedIn twins (the Webflow Senior Salesforce Developer case earlier this week). company+title+city dedupe catches it.
4. **Never invent a posted date.** Undated Workday rows carry an em-dash `Posted`; skip, never assign a date.
5. **Title rule is a hard filter.** Rogers `Lead Management Operations` and ServiceNow's own CRM sales roles mention the platform but are sales/marketing ops, not Platform Admin/Dev I — excluded. Same for Bell/Gov Canada hits where the platform is one skill among many.
6. **Always check the canonical employer page before counting a role live.** Bell's ServiceNow roles look fresh on aggregators; canonical pages say "filled" — verified closed.
7. **Adzuna detail pages are not independently verifiable** (HTTP 405/500 to extractors). Trust the dated sweep file + URL dedupe against the board; never add an Adzuna-only role without a directly-verifiable employer page.
8. **Import before build.** `import_fresh_rows.py --days 7` promotes dated SN/SF rows into README tables; `build_site.py` must run after any README change or the live page stays stale. Commit `public/jobs-data.json` + `public/index.html` alongside `jobs.json` — editing `jobs.json` alone never reaches the page.
9. **Commit + push to `main` triggers GitHub Pages auto-deploy** via `.github/workflows/pages.yml`. Verify `public/index.html` carries the new build stamp after `build_site.py`.
10. **Scope:** Toronto-first, Canada-wide. Fresh rows include Ottawa/Montreal/Calgary — keep Toronto-first ranking, don't hard-reject other Canadian cities.
