## Lessons for future runs
1. Adzuna API is the most reliable freshness source for this board — absolute dates, no walls, Toronto+Ontario geo scoping works. Always request page 2 (counts up to 75/query).
2. The 20:00 EST scan already pulls the Adzuna firehose into jobs.json; the recurring gap is rows present in jobs.json but not rendered in the README tables — diff jobs.json against README before hunting new sources.
3. LinkedIn guest detail pages are flaky (join wall ~50%); when blocked, search snippets still give title/company/location/deadline — enough to merge with posted=verify date.
4. Cognizant careers pages sit behind Cloudflare verification in this environment; rely on search snippets + LinkedIn mirrors for Cognizant roles.
5. Dedupe must run on URL-normalized keys AND title|company|city fingerprint — the same requisition appears under adzuna.ca/details and LinkedIn URLs.
6. Scope per board spec: Toronto-first, Canada-wide OK; contract/FT platform roles (SN/SF dev/admin/architect/ITAM/CMDB) in; sales-recruiter, intern, co-op, pre-sales titles out. APPLIED.md is a hard exclude.
7. Only README.md + jobs.json changed this run; pages.yml deploys GitHub Pages automatically on push to main (README.md is a trigger path). No manual site build needed.
