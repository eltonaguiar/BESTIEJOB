## Process lessons for future agents
1. Dedup happens inside the scan (fresh vs merged counts); do not re-add URLs already in README/FRESH_JOBS. The merger (`tools/jobs_merge_inbox.py`) targets permanent `### ServiceNow jobs (` / `### Salesforce jobs (` tables — the live README currently uses DAILY-SCAN blocks regenerated by `daily_job_scan.mjs`, so the scan is the publish path, not the inbox merger.
2. `git` at `/mingw64/bin/git` is blocked (Permission denied). Always use `C:/Program Files/Git/cmd/git.exe` for git ops in this repo. `gh` shells out to git, so set `PATH="/c/Program Files/Git/cmd:$PATH"` before `gh` commands.
3. Remote `main` advanced under this run (a parallel `fresh CA sweep` commit `44c075b [skip ci]` landed at 01:02Z). Rebase onto `origin/main` before pushing; conflicts in `jobs.json`/`public/*.json` resolve to the newer scan's version.
4. pages.yml deploys on push to `main` (paths: `public/**`, `README.md`, `tools/build_site.py`, workflow file) AND on schedule `:35 * * * *`. Commits with `[skip ci]` do NOT trigger the workflow — use `workflow_dispatch` (`gh workflow run "Deploy GitHub Pages" --ref main`) for immediate deploy verification.
5. Zero new verified jobs is a valid result; an unavailable source is not a zero. This run found fresh postings, but Workday blockers mean bank/employer-direct coverage is incomplete — revisit those tenants after backoff.
