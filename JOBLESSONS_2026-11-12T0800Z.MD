## Patterns / lessons (re-confirmed)
1. **Zero fresh merges on most hourly runs is the norm, not a failure.** Adzuna/LinkedIn/Workday re-surface the same requisitions hourly; nearly every URL was already on the board or outside the 30-day window.
2. **Dedupe before trusting "fresh."** Roles that look fresh (e.g. Cognizant SAM Developer, Nov 11) are often already on the board via a different URL. Normalize by role + company + location, not URL alone.
3. **Freshness first:** only today/yesterday postings. Adzuna API `created` date recycles IDs — use the detail page's JSON-LD `datePosted`, not the API `created`.
4. **`verify_links.py`:** only `404/410/451` = dead; `403/429/5xx` and transport errors are bot-walls on live postings — keep them. Rows with `verifiedAt` within 6h are not re-probed.
5. **Vendor twins** (two staffing firms, same client req) are distinct postings — keep both. LinkedIn job-id equality (same trailing numeric id) is a hard dedupe signal even when titles differ.
6. **README tables need explicit regeneration** — null-runs that find 0 new rows don't refresh the rendered table date/counts, so `README.md` can lag `jobs.json`.
