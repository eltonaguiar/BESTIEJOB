## Patterns / lessons for future agents
1. **`fresh_ca_scan.py --days 2` times out at 300s** on Job Bank + Eluta. For hourly runs, query Adzuna API directly (~68 calls, <60s) and save the full Job Bank/Eluta sweep for dedicated runs. The Adzuna demo key works without env vars.
2. **Workday CXS probe works with curl_cffi** (now installed). 10 known Canadian tenants probed; only `salesforce.wd12` answered among the 15-workday list used by the partner script. Use `searchText` appended with city (e.g. "ServiceNow Toronto") for global boards (Accenture, Salesforce) since page 1 is relevance-sorted and non-Canada.
3. **Workday search results can match keywords without the title naming the platform.** CIBC "Sr. Consultant, Data Developer" and Manulife "Senior Business Analyst" both matched "ServiceNow" in page text but neither title nor description meaningfully references it. Always verify title + description before adding.
4. **GDIT ServiceNow System Administrator is a real SN role but US-only** (jobLocationCountry = USA, supporting NIH/NIAID). Remote-looking Workday reqs ("Any Location / Remote") are often US federal contracts — check `addressCountry` before adding.
5. **Partner/sponsor scanning yields little directly:** 38 sponsors probed, board slug identity check rejects most guesses (demo/trial boards, wrong companies). Only `salesforce.wd12` answered among Workday tenants. Keep as confirmation lane, not primary source.
6. **Public sector is hit-or-miss:** City of Toronto tiles render server-side with dates (9 tiles, 0 new this hour); OPS gojobs is behind Radware Bot Manager and cannot be scraped; Job Bank OPS fallback returned 8 articles, 0 new.
7. **Rogers and Bell career portals are effectively dead ends:** jobs.rogers.com returns CloudFront 403; jobs.bell.ca shows 0 reqs for both servicenow and salesforce. Re-check weekly, not hourly.
8. **Consecutive zero-match hours are normal.** This is the second consecutive hourly scan with 0 new verified SN/SF Toronto jobs. Don't force a README rebuild when nothing changed — it creates noise without value.
9. **curl_cffi is now installed** in this environment — Workday CXS and public sector scans that previously failed can now run. Verify availability before planning scans that depend on it.
