## Reusable patterns for the next agent
- **Dedupe URL first, then company+title.** This run's URL pass caught 4 hidden dupes
  (BMO, 2× Apex, Jobgether) that the feed's fresh dates made look new.
- **Same vendor + same title family = one req.** Synechron/Delpath senior-vs-plain
  variants and Morson's two HRSD ads are reposts; different *vendors* on one client
  req stay separate (user applies to each).
- **Adzuna `created` ≠ first posted.** Re-created ads carry today's date; if the URL is
  already in README, it is old. Always check the README URL set.
- **LinkedIn job-id equality is a hard dedupe signal** even when titles differ
  (Amyantek 4489682441).
- **Adzuna geo passes matter.** National `max_days_old` search is mostly other provinces;
  `where=Toronto` + `where=Ontario` keeps GTA roles on top.
- After inserting rows: `sort_readme_tables.mjs` → `fix_counts_r8.py` → `sync_readme_to_jobs.mjs`
  → `tools/build_site.py`. Verify with `fix_counts_r8.py` (`CONSISTENT: True`) and confirm
  every new job id appears in `public/jobs-data.json`.
- `sync_readme_to_jobs.mjs` can add rows that were in README but not in the feed
  (4 this run) — that is expected and desirable.
