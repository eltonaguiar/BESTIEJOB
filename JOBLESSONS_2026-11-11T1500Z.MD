## Patterns / lessons

1. **Adzuna dated API is well-covered:** The fresh-ca Adzuna sweep (68 calls) found nothing new today because the Adzuna jobs for this window are already on the board via previous scans (workopolis, linkedin-guest, adzuna-round files). The Adzuna channel is saturated for this date window.
2. **LinkedIn direct postings are the main source of new SN/SF Toronto jobs:** Today's 3 new additions all came from LinkedIn (Lyft, CGI) and Workday (Altus Group) via the hermes-cron inbox file, not from the fresh-ca Adzuna/JobBank/Eluta sweep.
3. **Indeed viewjob pages don't expose posted dates:** The iVedha Salesforce Technical Consultant job could not be added because the Indeed extraction returned no `postedDate`. The board merger requires absolute YYYY-MM-DD dates. Lesson: when scraping Indeed, capture the date from search-result pages or job-bank APIs, not just viewjob.
4. **URL normalization catches near-dupes:** Altus Group Salesforce Business Analyst (R0014075) appeared in gap-channels with a non-`/en-US/` Workday URL but was already on the board via ats-sweep with the `/en-US/` URL. `normalise_url()` handled this, but only when both formats are present — the gap-channels file's variant wasn't caught because it was already in the board under the other format.
5. **30-day window excludes MLSE:** The MLSE Salesforce Engineer/Developer (posted "30+ Days Ago") falls outside the board's 30-day retention window. Not eligible.
6. **hermes-cron inbox file is a rich source:** `hermes-cron--2026-11-11--v1.md` had 7 rows, 4 already on board, 3 new. Running the hourly scan and then checking today's inbox files (not just fresh-ca) yields additional verified additions.
