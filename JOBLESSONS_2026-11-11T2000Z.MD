## Source-reliability notes
- **adzuna.ca `/details/<id>` returns HTTP 403 to curl** (WAF), even with a browser UA.
  Do NOT treat 403 as a dead link. Liveness is better established by the URL being present
  in the latest `jobs.json` (Adzuna API returned it) — all merged rows satisfied this.
- Adzuna `postedDate` ≈ the Adzuna `created` timestamp (today's batch ≈ 12:2xZ), NOT the scan
  time — reliable enough as a "Posted" date. LinkedIn `postedDate` is date-only (00:00Z).

## Repo pipeline (run in this order after editing README tables)
```
node scripts/sort_readme_tables.mjs README.md      # newest-Posted-first
python scripts/fix_counts_r8.py                    # recount + rewrite 5 count spots + verify
node scripts/sync_readme_to_jobs.mjs               # README -> jobs.json + public/*/jobs.json (superset)
python tools/build_site.py                         # public/jobs-data.json + public/index.html
```
- The live site **builds from `jobs.json` as a superset**, so freshly-scanned jobs often
  already render on Pages before they are in README. The README merge is the curated delta;
  re-running `build_site.py` just refreshes the build stamp / curated view.
- `sync_readme_to_jobs.mjs` may rewrite the jobs.json copies with LF vs the repo's CRLF,
  producing line-ending-only "M" diffs. If `git diff --ignore-all-space` shows no content
  change, `git checkout --` those copies to keep the commit tight.

## Reusable patterns for the next agent
- Dedupe on **company + title + city**, not URL. Subsidiary aliases (Reonomy↔Altus,
  CloudKettle↔Bell, Ateko/FX Innovation↔Bell, LGS↔IBM) hide duplicates.
- **Multi-city reposts** (BDO, Triunity) are one requisition — keep one row, note the other cities.
- Prioritise **Elite/Platinum SIs** (TCS, Cognizant, Infosys, Accenture, Deloitte, Capgemini,
  Wipro, HCL, KPMG, CGI, RSM) — they reliably post cadence-fresh Toronto SN/SF reqs.
- The hourly GitHub Action refreshes `jobs.json`/site but **does not touch README** — so the
  README-vs-feed delta is where a manual/cron merge adds value every hour.
