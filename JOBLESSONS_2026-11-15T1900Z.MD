- Indeed.ca search blocks curl (403); LinkedIn guest job detail returns 422; jobs.gc.ca unreachable. web_search snippets are OK for discovery, not verification.
- landthatrole.com /job/ links are redirect wrappers; roles found there (PwC, OSI Digital, Docebo, Altus, Benevity, Make-A-Wish) were already in jobs.json from the adzuna/LinkedIn harvest.
- jobs.json dedupe key is URL — strip `?utm_*` query strings before comparing against readme.md, else you get false "misses" (72 query-stripped misses reviewed this run; mostly legacy postings from 11-14 and older, or classification false positives such as Revenue Management Labs "Consultant" flagged isServiceNow and la Vie en Rose email-marketing internship flagged isSalesforce).
- Merge-conflict hazard: the scheduled hourly action and a manual scan can push to main in the same hour (happened this run: 18:43Z sweep vs 14:00 EST manual scan). Always fetch + merge (never rebase on this repo — case-insensitive path issues) before pushing, and re-verify counts after resolving.
