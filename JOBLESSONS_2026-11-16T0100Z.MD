## Lessons for future agents

1. Dedupe on normalised URL (+ LinkedIn job id equality as a hard signal). Vendor twins (two staffing firms, same client req, same title) are DISTINCT — dedupe on URL only, never title+company.
2. APPLIED.md is a hard exclude — its URLs never re-enter the tables (build_site hides 45 applied rows).
3. Workday CXS is reachable but heavily rate-limited from this host; treat it as a single-call-at-a-time source with gaps between tenants. Bursts → 422/429 across the board.
4. LinkedIn guest search is the best hourly freshness oracle (`f_TPR=r86400`, absolute `datetime`, ~6 s/query); `start=25` re-serves page 1 — don't bother. Guest API 429s and can return an authwall with HTTP 200 + identical body — test body length/digest, not just status.
5. README tables carry pre-existing debt (stale heading counts, `board_invariants` red at ~136 errors regardless). The additive merger with read-safety check is safe; don't chase perfect count reconciliation.
6. Commit discipline: `[skip ci]` on all board commits (non-skip pushes run the chronic red audits). pages.yml redeploys GitHub Pages only on a main push — no push, no redeploy.
7. 0 net new curated rows this hour is a valid, verified outcome — do not re-run the merge "just to have a commit".
