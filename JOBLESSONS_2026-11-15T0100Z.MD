## Lessons for future agents
1. **`jobs_merge_inbox.py insert_rows` glues each section heading to its blurb on one line** (`### ServiceNow jobs (N)_developer..._`). That breaks `parseReadme()` in `tools/sync_readme_to_jobs.mjs` (0 rows parsed -> jobs.json goes stale). After every merge, split the three headings back onto their own lines (`### ...` / `_blurb_` / `<details>`).
2. **Never run the merger with `--bump-inbox` on a full `inbox/`** — it rewrites every historical submission file (331 files deleted + re-created in one run). Use additive merge without `--bump-inbox`, then remove today's submission file once its rows are in README (merged rows live in README; inbox files are redundant copies).
3. **Commit without `[skip ci]` when you need the live page updated now.** `pages.yml` is push-triggered on `public/**` + `README.md`; `[skip ci]` suppresses it and leaves the page stale until the :35 UTC cron.
4. **When `origin/main` advances mid-run, generated `public/*` and `jobs.json` conflict on rebase.** Don't conflict-resolve build artifacts: `git rebase --abort`, `git reset --hard origin/main`, then regenerate the pipeline (scan -> merge -> sync -> build_site) on the current base and push again.
5. Adzuna returned intermittent HTTP 503s on a few angles (`servicenow solution architect`, `servicenow HRSD`, `salesforce architect` variants). Those queries still yielded results through overlapping angles; treat 503s as partial, not fatal, and don't retry the same query blindly.
6. This window's scan was **Toronto/Canada-first but not Toronto-only** — the board keeps Canada-wide SN/SF/IT-platform roles, Toronto first. Freshest postings this run were dated 2026-11-14 and 2026-11-15.
