## Patterns / lessons
1. **Null runs are the norm.** Zero fresh table rows on most hourly runs — do not treat a null scan as a failure.
2. **Verify candidates against full README text, not a parsed subset.** ~190 of 6,746 table rows use URL variants a naive regex misses; direct substring search on the file is the reliable dedupe check.
3. **Dedupe before trusting "fresh."** The same role arrives via employer ATS and LinkedIn under different URLs; normalize by company+title+location, not URL alone. All 14 fresh candidates this run were already on the board.
4. **Bell filled-roles gate holds.** All checked Bell ServiceNow reqs are filled/410; don't re-surface filled roles each hour.
5. **Adzuna rate-limits (503/429) on ~4 queries/hour.** Pace queries; don't increase concurrency. Rate-limited keywords are covered by other Adzuna queries next hour.
6. **Partner career sites rarely publish dates / rarely have entry-level Platform Admin/Dev I.** GC platform work comes via prime vendors on their own ATS; nothing fresh dated Nov 11–12 this hour.
