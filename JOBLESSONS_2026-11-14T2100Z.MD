## Lessons / patterns for future runs
- The 20:10 UTC hourly scan already runs Workday CXS + Adzuna + `gap_scan.mjs`, so a manual re-scan one hour later adds almost nothing: Workday "Posted Today/Yesterday" Toronto roles surface in the same hourly run they're posted.
- Salesforce Data 360 / CDP engineering roles are `salesforce`-tagged but senior (Engineer III/Lead) — they match the broad "Salesforce" scan but not the user's entry-level Platform Admin / Platform Developer I emphasis.
- CIBC/Manulife/GDIT: a "ServiceNow" mention on an ATS page is not a ServiceNow role — require the platform/cert in title or body before adding (title + description match, not page keyword match).
- Mirror reposts (Built In Toronto reposting an SS&C role already tracked via LinkedIn/README) are caught by URL + company+title dedupe — no double-listing.
- Rogers/Bell/Telus career portals remain unreachable or empty (Cloudflare 403 / 0 reqs) — check weekly, not hourly.
- Greenhouse/Ashby/Lever ~84-board sweep returned zero fresh Canada SN/SF roles within 2 days — aggregator + Workday coverage is the effective freshness channel for this board.
