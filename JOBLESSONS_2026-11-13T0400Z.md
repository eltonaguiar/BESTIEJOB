## Patterns / lessons for future agents
1. **A 0-merge hour is a valid, honest result.** When the automated hourly Action + prior sweeps are
   current, the board simply has no gaps. Report `0 merged` with the dedupe proof; never pad the board
   with duplicates or expired reqs to look productive.
2. **Verify the application deadline / canonical page, not the aggregator "posted" date.** The EDC
   Senior Developer SN CSM said "posted" on several aggregators this week but its deadline passed
   2026-09-16. Stale re-indexes are the #1 source of false "fresh" postings.
3. **Indeed `jk=` URLs are opaque.** Resolve employer+title before dedup. `jk=67fc0fb9239ce204`
   is KPMG "Consultant, ServiceNow Developer" — already on the board via Workopolis/LinkedIn. Dedup
   on company+title+city as a backstop to URL equality.
4. **Direct career-page postings are usually mirrored.** Cognizant `careers/00071305431`, Salesforce
   Workday `JR367615`, and Scotiabank `jobs.scotiabank.com` items all already exist under
   LinkedIn/Workopolis/Adzuna URLs. Check all mirrors before declaring something new.
5. **Partner/bank/gov sweeps yield ~0** because Adzuna + LinkedIn guest + Workday CXS + SmartRecruiters
   already scrape these ATSes. Their value is *confirmation*, not new rows.
6. **A GitHub Action runs the same hourly pipeline.** Always `git fetch` + `git pull --ff-only`
   before committing, or you clobber the Action's `jobs.json`/`public/` rebuild. This hour: pulled
   `8dea9c1..3618e6c` first, then committed only the lessons file (matching the `1c0e123` null-run precedent).
7. **The live site is the deliverable, not just repo files.** Confirm `index` + `jobs.json` return
   HTTP 200 and `meta.scrapedAt` is recent before/after any merge.
