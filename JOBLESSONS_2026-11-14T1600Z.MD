## Lessons / patterns for future agents
1. The board refreshes hourly (~10:00 EST) and already captures the freshest LinkedIn/Workday/Adzuna Toronto SN/SF roles. A mid-hour re-scan frequently yields 0 genuinely new rows — don't force rows that fail the bar.
2. Adzuna detail pages return **403 (Cloudflare)** to direct fetch; rely on the API `description` field, not the detail page, to confirm the ServiceNow platform mention. Never add an ITSM/CMDB-titled role without platform confirmation.
3. Workday CXS `postedOn` is relative ("Posted Today"/"Posted Yesterday"/"Posted N Days Ago"); only keep Today/Yesterday for the hourly freshness window.
4. Rogers/Bell/government portals are **weekly, not hourly**: Rogers job table renders async (browser needed), Bell returns zero reqs for servicenow/salesforce, jobbank.gc.ca full-text search is noise (trust only title-named platform).
5. Salesforce targeting is strict: Platform Administrator / Platform Developer I / entry-level only. Generic "Salesforce Developer" and executive/VP roles are excluded. No qualifying SF role surfaced this hour.
6. LinkedIn direct URLs must be deduped by both normalized URL and `title|company|city` fingerprint before adding (vendor mirrors and LinkedIn/Workday duplicates of the same requisition exist).
7. When nothing qualifies, the correct deliverable is this lessons file plus a confirmed-good jobs.json — no empty/forced additions to README or public/.
