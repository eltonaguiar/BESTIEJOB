## Source reliability (this run)

- Workday CXS: reachable, returns ~4–5 SN/SF postings per employer per query, BUT the scan's direct `tenant.wdN.myworkdayjobs.com` API was HTTP-429 rate-limited on nearly every board (Salesforce, BMO, TD, Moneris, BDO, CAAT, Medcan, Altus, IKO, Huron, Irving Oil, McKesson, Brookfield, GDIT, Resolve Tech). Memory note: Workday CXS IS reachable via the `wdN` host with `curl --compressed`; the bare tenant host is NXDOMAIN and urllib is blocked. Prefer the curl path, throttle requests, and treat 429 as "retry later", not "no jobs".
- Adzuna Canada: works (376 postings) but demo app_id/app_key get HTTP 503/429 on several queries; space out queries and don't treat a 503 as empty.
- LinkedIn guest: works (166) but throttled hard — keep the 1.8s inter-request gap and 2-worker limit; guest detail pages return 422, don't chase them.
- Greenhouse/Lever/Ashby/remote boards: reliable, low volume (1–16 each). Good for filler, not the main harvest.

## Patterns for future agents

1. Lead with Workday CXS for Canadian enterprise SN/SF (banks, insurers, pension funds, telcos) — it's the most consistent Canadian source, but respect 429 backoff and use the wdN + curl path.
2. Adzuna + LinkedIn guest capture the agency/contract volume; date-sort Adzuna (`sort_by=date&max_days_old=14`) to surface today's postings first.
3. Check partner/Elite firms directly (gap scan): Ateko/Bell, Cofomo, Everforth, Coaxxion, CloudKettle, Lane Four, Crossfuze — none dateable this run, but re-check quarterly as careers pages change.
4. When a run finds +0 new curated jobs, that's a valid result — commit the feed refresh and pages rebuild anyway so the board stays current; record a null lessons note rather than forcing duplicates.
5. Keep `README.md` counts in sync after any merge (ServiceNow / Salesforce / Other headings + `Show N postings` detail counters); the merger bumps them automatically in additive mode.
