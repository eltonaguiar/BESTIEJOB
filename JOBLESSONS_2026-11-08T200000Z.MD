## 5. Lessons / patterns for future agents
- `careers.servicenow.com` is the most reliable verified source for Toronto ServiceNow roles; postings are real and current (Nov 5–8, 2026).
- ServiceNow careers jobs are mirrored to `jobs.smartrecruiters.com` with identical requisition IDs — dedupe by URL alone under-counts duplication; match on requisition ID / title / company.
- `ca.indeed.com/viewjob?jk=<shortkey>` (e.g. `jk=bmo-sam-admin`, `jk=compugen-itom`) look synthetic/placeholder — low verification value; prefer employer careers domains (`careers.servicenow.com`, `careers.salesforce.com`).
- Do not run the full inbox merger hourly — it reprocesses ~150 historical harvest files and is destructive. Scope merges to a single dated submission file (`inbox/<model>--<YYYY-MM-DD>--v<N>.md`).
- Git is blocked on this Windows host (Windows Security, `git.exe` Access is denied) — push via `gh` Contents API (`gh api --method PUT /repos/eltonaguiar/BESTIEJOB/contents/README.md --input <file>`). `gh` is a native Windows program: pass native `C:/...` paths for `--input`, never MSYS `/tmp`.
- `pages.yml` builds the live site from README tables on push to `main` — pushing README.md is sufficient to update GitHub Pages; no separate `index.html` edit needed.
