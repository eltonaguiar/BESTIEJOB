## Patterns / lessons for future hourly runs

- Adzuna gap-scan keyword variants surface roles the main feed misses, but nearly all are already tracked — null hourly runs are normal (the 13:00 EST run was 0 new).
- Adzuna API `created` dates are recycled (an ad first posted Nov 6–7 can show `created` Nov 11–12); cross-check the true date on the employer/aggregator page before adding.
- Adzuna detail pages return 403 (CloudFront) from server and browser alike — a 403/429/5xx is a bot wall on a *live* posting, never a dead signal; freshness comes from the API date plus cross-source confirmation.
- `jobs.bell.ca` (Phenom) keeps rendering closed requisitions — always check the Application Deadline; this run's Bell SN role expired 2026-10-07.
- Job Bank full-text search is noise (matches unrelated NOC postings); trust only hits whose *title* names the platform.
- ServiceNow-the-company hires sales/SRE/security in Toronto, not platform admin/dev — fresh platform work comes from partners/consultancies and end-user employers (BMO, TD, Rogers, Bell).
