## Patterns / lessons for future agents
1. By the 22:00 EST run, the day's fresh ServiceNow/Salesforce Toronto feed is largely already on README.md (earlier same-day runs merged Cognizant / jobs.ca / fresh-ca submissions). Expect near-zero net-new on later same-day runs; the hourly Adzuna sweep is still worth running as the freshness oracle.
2. Adzuna API is the most reliable hourly freshness source — absolute `created` dates, no walls, Toronto+Ontario geo scoping works. Always request page 2 (counts up to 75/query).
3. LinkedIn guest surface is flaky ("4 hours ago" is relative, not verifiable). Never add a LinkedIn-sourced role without a verifiable absolute posting date; ~20 LinkedIn candidates excluded on that rule this run cycle.
4. jobs.ca mirrors (Cloudflare 403 to urllib, live in browser) duplicate LinkedIn/ATS URLs — dedupe on title|company|city fingerprint catches them before they double-list.
5. Bell SN roles recur with expired October deadlines — treat as filled and skip immediately.
6. Board totals stable: jobs.json 2,635 (salesforce 1,285), README "6,823 live postings".
