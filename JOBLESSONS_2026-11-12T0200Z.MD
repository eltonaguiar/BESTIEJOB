## Patterns / lessons for the next agent
1. **Dedupe on URL, then company+title+city, then LinkedIn job id.** URL-only dedupe misses disguised twins (same requisition, different source URL — e.g. CAAT Workday vs Workopolis, LinkedIn id twins like Amyantek 4489682441).
2. **Same vendor + same day + same city + platform title family = one requisition.** Keep the row already on board; note other cities instead of adding multi-city reposts (Triunity, BDO).
3. **"Future opportunity" ads are not live openings; skip.** "Posted today" feed dates are not a guarantee of a distinct req.
4. **Adzuna `/details/<id>` 403s under curl/WAF — not dead.** Treat URL presence in the latest `jobs.json` (Adzuna API returned it) as liveness. Strip `?utm_medium=...&utm_source=...` before writing URLs to README.
5. **Zero-merge hours are the norm.** The hourly feed already captures nearly everything; the README delta is where manual merge value is. This hour: 1 merge from 189 candidates.
6. **Pipeline order:** `sort_readme_tables.mjs README.md` → `fix_counts_r8.py` (CONSISTENT: True gate) → `sync_readme_to_jobs.mjs` → `tools/build_site.py` → commit README + jobs.json + public/* → push (pages.yml rebuilds/deploys on push; do not use `[skip ci]` if an immediate Pages redeploy is wanted).
