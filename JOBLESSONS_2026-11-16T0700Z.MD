## Lessons / patterns for future agents
1. **LinkedIn guest DOM is the most reliable freshness source this hour** — no authwall on `ca.linkedin.com/jobs/search?f_TPR=r86400`; cards show relative times ("X hours ago") and absolute job ids in `/jobs/view/<slug>-<id>`. One query ≈ 60 cards in ~6 s. Retry once if body is empty (intermittent len-0 responses).
2. **Adzuna API list works; detail pages don't** — `api.adzuna.com/v1/api/jobs/ca/search/1` with `content-type=application/json` (not `content_type`) and `max_days_old`/`sort_by=date` returns fresh rows, but `adzuna.ca/details/<id>` returns CloudFront 403 from this host and browser. Cannot verify description relevance; never add generic-titled ads on API date alone (Adzuna recycles ids; old postings resurface under new ids).
3. **Workday CXS reachable via bash curl only** — `curl --compressed` with `Origin`/`Referer` headers to `https://{tenant}.wdN.myworkdayjobs.com/wday/cxs/{tenant}/{site}/jobs`. Known 200 pairs: bmo.wd3/External, td.wd3/TD_Bank_Careers, cibc.wd3/search, manulife.wd3/MFCJH_Jobs, interac.wd3/interac, gdit.wd5/External_Career_Site, salesforce.wd12/External_Career_Site, accenture.wd103/AccentureCareers. Canadian tenants showed no "Posted Today" SN/SF this cycle; `postedOn: "Posted Today"` is NOT a Canada signal (read the location slug). Never run curl from Python subprocess (WinError 5) — use the terminal tool. Space calls; repeated rapid fetches come back empty/rate-limited.
4. **"Posted Today" on Workday ≠ new posting** — a req can show "Posted Today" while already on the board with an older postedDate; always diff postedDate + alternates before re-adding.
5. **Rogers date-sorted list is browsable but sales/retail-heavy** — `jobs.rogers.com/search/?q=&sortColumn=referencedate&sortDirection=desc` renders `<tr>` rows with absolute dates; no SN/SF titles in the recent window. Bell shows (0) in-browser → zero reqs, re-check weekly.
6. **Partner "careers" pages often dead-end** — Lane Four postings are undated email-to-apply placeholders. Check partner portals monthly, not hourly.
7. **Origin's GitHub hourly scan (06:31Z) ran ahead of this cron** and fast-forwarded main to beb19b5 (2,767 listings). When pushing, expect possible non-fast-forward from the scheduled scan; rebase (not rebase-blocked here — no case-only filename collisions) and retry. Lessons commits use [skip ci].
