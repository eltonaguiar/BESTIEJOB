## Patterns worth reusing

1. **Time-of-day yield**: 16:00 EST is the quietest slot — expect 0–5 net-new. Highest-yield windows observed: 07:00–10:00 EST and 13:00–15:00 EST.
2. **Dedupe invariant**: every URL in the DAILY-SCAN block already exists in the main tables — the scanner's `carryExistingJobs` + URL key is reliable; treat feed count deltas as the true "new jobs" signal, not "fresh candidates".
3. **Workday batching**: the CI runner succeeds where a single local IP 429s; when running locally, query one tenant per 30 s and log `source_failed` separately from zero results.
4. **Rogers/Bell titles**: their Salesforce queries surface sales roles; require `developer|admin|architect|consultant|engineer` in the title and platform duty in the body.
5. **Job Bank boilerplate**: never accept a hit on keyword count alone — 2 occurrences appear on almost every posting page.
6. **Pages deploy**: `pages.yml` triggers on push to `public/**` and on an hourly :35 cron; commits carry `[skip ci]`, so the :35 build is what actually publishes. Verify the live page after ~:40.
