## Blockers / environment notes (for future agents)

1. **LinkedIn guest search is blocked in cron/fresh-profile sessions.** `new_tab` on `linkedin.com/jobs/search?f_TPR=r86400` returns an empty page (authwall). Do not treat `len==0` as "no jobs" — it's a blocker. Retry when a logged-in profile is available, or rely on web_search snippets + per-posting verification.
2. **web_extract backend is ddgs (search-only) in this session** — cannot fetch arbitrary page content (Rogers careers date-sorted page failed). Use `new_tab` + DOM reads in the browser instead when a working profile is available.
3. **curl_cffi is unavailable in the Hermes venv** — Workday CXS search and LinkedIn guest API via curl degrade gracefully; LinkedIn guest search works via browser DOM only when not authwalled.
4. **Git race:** the hourly GitHub Action pushes independently. Always `git pull --ff-only` (rebase) before pushing; local main was 1 commit behind origin/main at the start of this run.

## Patterns / lessons for future agents

1. **Hourly general web searches rarely surface anything not already captured.** The board was refreshed at 16:15Z this afternoon (just before this 17:00Z run); this run found 0 new. An empty merge is a valid outcome — do not force stale or off-target roles onto the board to avoid an "empty" run.
2. **Adzuna + LinkedIn together give strong freshness coverage**, and they cross-validate: every platform-named Toronto role surfaced this hour was already on the board. Neither alone is sufficient, but together they cover the population.
3. **Freshness first: prioritize today/yesterday.** EQ Bank (1 week old, Senior CMDB) and Altus Group (Oct 30) were correctly excluded even though they name the platform — they fall outside the hourly freshness window and aren't entry-level Platform Admin/Dev I.
4. **Classify on title, not keyword context.** Non-platform roles (network reliability, data integration, AI agentic engineer) appear under SN/SF keyword queries because the platform appears in the body. The board rule stands: title must name ServiceNow/Salesforce or a module/cert (CSA/CAD/CIS, CMDB, ITSM, ITOM, Apex, LWC, Agentforce, CPQ). Platform Admin / Platform Developer I (entry-level) is primary; generic "Salesforce Developer" is secondary.
5. **Dedupe on normalized URL + LinkedIn job id**, not the title/slug. Interac's URL matched an existing row exactly; confirm with `jobs.json` before adding.
6. **Named-employer career-site scans beat keyword scans for telcos/financials.** Rogers' date-sorted crawl and bank Workday tenants (BMO, TD, CIBC, Interac) are the reliable sources for platform roles; generic keyword scans return sales/analyst noise.
7. **When 0 jobs are found, commit nothing to jobs.json/README/public.** Only record lessons (this file). Touching the board with no verified additions creates noise and risks merge conflicts with the next hourly scan.
