## Patterns / lessons for future agents
1. The board is maintained by frequent scans; by the 14:00 EST run, the day's fresh ServiceNow/Salesforce Toronto feed is largely already on `README.md` (earlier runs merged Cognizant / jobs.ca / fresh-ca submissions). Expect near-zero net-new on later same-day runs.
2. `jobs.json` is regenerated by the GitHub Action hourly — use it as the candidate list, but dedupe rigorously against ALL URLs in `README.md` (not just table rows) before submitting.
3. LinkedIn is a login wall (HTTP 422): never add a LinkedIn-sourced role without a verifiable absolute posting date. This run excluded ~20 LinkedIn candidates on that rule.
4. Adzuna is a real source for this board (461 feed jobs; many already on `README.md`), but adzuna detail pages were not extractable this session — 2 genuine Toronto SN/SF roles (Amicis ServiceNow DPRM; CloudLabs Salesforce Architect) are queued for re-check once page extraction works.
5. Bell ServiceNow roles recur with October deadlines — treat as filled/expired and skip immediately rather than re-probing each cycle.
6. Publish chain (when there IS something to merge): `python3 tools/jobs_merge_inbox.py --max-per-table 5000 --bump-inbox` → `node scripts/sync_readme_to_jobs.mjs` → `python3 tools/build_site.py` → `python3 scripts/check_site_links.py` → commit `README.md`, `jobs.json`, `public/` to `main` (no `[skip ci]` so `pages.yml` redeploys https://eltonaguiar.github.io/BESTIEJOB/).
