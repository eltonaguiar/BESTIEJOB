## Note on tooling

`tools/jobs_merge_inbox.py` rewrites every `inbox/*.md` it reads, bumping `v<N>` and
stamping the file. Running it by hand therefore renames peer submissions too; this run
was done with the other submissions moved aside and restored afterwards, and the
auto-bumped peer files were reverted so the commit contains only my own inbox file.
`rm -f README.BAK_*.md` in that same command deleted the tracked archives — they were
restored with `git checkout -- 'README.BAK_*.md'` before committing. Don't combine a
merger run with a bulk `rm` of tracked files.
