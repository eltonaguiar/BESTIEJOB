## Dedupe lessons (read before merging)

- **Dedupe by title+company+date, not URL only.** BeachHead "Senior ServiceNow Developer (SAM/HAM)" Toronto 2026-11-11 surfaced via beach-head.com, but the same requisition was already on the board under its LinkedIn URL (`.../senior-servicenow-developer-sam-ham-at-beachhead-4489985060`). Skipped as a near-duplicate.
- **jobs.ca rows mirror LinkedIn.** Apptoza and CGI jobs.ca entries say "Apply on LinkedIn". Open each page to confirm date/company/location before adding; the jobs.ca URL itself may not be the canonical source, so check whether the LinkedIn twin is already on the board.
- **Cognizant careers has locale variants** (`/ca-en/`, `/uki-en/`, `/us-en/`, `/apj-en/`) for the same requisition — normalise the job id (`00070949051`) when deduping.
- **jobs.json sync matches loosely by title+company**, so 3 of the 4 new README rows were already title-matched in jobs.json (added=1 net new URL). That's expected — the board dedupe is the source of truth.
